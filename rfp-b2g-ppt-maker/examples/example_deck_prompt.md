# Example Full Deck Prompt

```text
Create a Korean B2G public-sector PowerPoint deck for:
Ⅱ. 기술 및 기능

Project:
서울시 지능형 CCTV 관제 고도화 사업

Evaluation focus:
기술 및 기능 - 사업추진내용

Base all content on:
- 제안서 원문: Ⅲ. 기술 및 기능부문 p45-p105
- 평가기준: 기술 및 기능 평가항목
- 디자인 시스템: 서울시 제안서 디자인 시스템 v0.1

Important numbering rule:
The source proposal section is "Ⅲ. 기술 및 기능부문", but final slide text must use "Ⅱ. 기술 및 기능".

Core story:
The deck must prove that the proposed architecture upgrades existing intelligent CCTV monitoring into a generative VLM-based operating system. It must connect requirements, HW/SW configuration, real-time performance, UI/XAI operation, and additional expansion proposals to the evaluation criteria.

Design rules:
- 16:9, 1920x1080
- Pretendard
- White background with navy header
- Red-orange-yellow gradient title accents
- Label, number card, circle node, arrow flow, funnel, and table components
- High information density with strict alignment and minimal shadow

Mandatory quantitative metrics:
- Use only metrics extracted from source pages.
- Separate target KPIs from operating-screen examples.

Slide structure:
1. Ⅱ-01 Section cover - evaluation promise
2. Ⅱ-02 Evaluation response summary - rubric-to-slide map
3. Ⅱ-03 Target system architecture - VLM-based monitoring upgrade
4. Ⅱ-04 HW/SW configuration - equipment and software roles
5. Ⅱ-05 Real-time processing architecture - latency and throughput assurance

Final requirements:
- Do not invent metrics.
- Keep Korean titles, numbers, and tables as editable PPT text.
- Include source-note comments or speaker notes for traceability.
```
